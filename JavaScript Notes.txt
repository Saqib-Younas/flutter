OOP IN JS

1. Class	Blueprint/Design hoti hai object banane ke liye. (Jaise "Car" ek design hai).
2. Object	Class ka ek real version. (Jaise "Toyota Car", "Honda Car").
3. Constructor	Special method hota hai class mein, jo object ke properties set karta hai jab object banta hai.
4. Encapsulation	Data ko object ke andar chhupa lena. Sirf methods ke through data access karna. (Security/Control ke liye)
5. Inheritance	Ek class doosri class ke features le leti hai. (Reuse code easily).
6. Polymorphism	Same function/method ka alag alag behavior hona different objects ke liye.
7. Abstraction	Sirf important cheezein dikhana, details chhupa lena. (Complexity ko easy banata hai).



Inheritance types

1. Single Inheritance
2. Multilevel Inheritance
3. Hierarchical Inheritance
4. Multiple Inheritance
5. Hybrid Inheritance


Type	Description	Example
Single Inheritance	Ek class doosri class se inherit karti hai.	Dog inherits Animal
Multilevel Inheritance	Ek class doosri class se inherit karti hai, aur woh apni subclass se inherit karti hai.	Puppy inherits Dog, and Dog inherits Animal
Hierarchical Inheritance	Multiple classes ek hi parent class se inherit karti hain.	Dog aur Cat dono Animal se inherit karte hain
Multiple Inheritance	Directly possible nahi hoti JavaScript mein, lekin mixins ke through achieve hoti hai.	Duck inherits from Animal and mixins like canSwim, canFly
Hybrid Inheritance	Multiple aur multilevel inheritance ka combination hota hai.	Bird inherits from Animal and mixin canFly

function reverseString(str) {
  // Step 1: String ko array mein convert karo
  let array = str.split(""); // Split the string into an array of characters

  // Step 2: Array ko reverse karo
  let reversedArray = array.reverse();

  // Step 3: Reversed array ko dobara string mein join karo
  let reversedString = reversedArray.join("");

  return reversedString;
}

function deepCopy(obj) {
    if (typeof obj !== "object" || obj === null) {
        return obj;  // Return primitive value
    }

javascript
