 1. Shallow Copy (سطحی نقل / upar upar ka copy)
Shallow copy sirf pointers ya references ko copy karta hai — actual data share hota hai, copy nahi hoti.

✅ Matlab:
Dono objects same memory location ko point karte hain.

Ek object mein change dusre object ko bhi affect karta hai.

🔸 Example:

int* a = new int(10);
int* b = a;  // shallow copy

*b = 20;
cout << *a << endl;  // Output: 20 (same memory)
❗Problem:
Agar aap ek object delete karo, dusre mein dangling pointer ban jata hai (dangerous!).



2. Deep Copy (گہری نقل / naya data bhi copy)
Deep copy mein actual data bhi copy hota hai, sirf pointer nahi.

✅ Matlab:
Nayi memory allocate hoti hai.

Har object ka apna independent copy hota hai.
Ek object mein change dusre ko affect nahi karta.

🔸 Example:

int* a = new int(10);
int* b = new int(*a); // deep copy

*b = 20;
cout << *a << endl;   // Output: 10 (separate memory)



Copy Constructor
 Urdu mein asaan explanation:
Jab aap ek object ko dusre object ke barabar karte hain (obj2 = obj1;) ya pass by value karte hain function mein, to compiler default copy constructor banata hai.
Lekin agar aapka object pointer ya dynamic memory use karta hai, to default copy constructor galat copy karega (shallow copy) — isliye humein apna khud ka copy constructor banana padta hai (deep copy ke liye).



class MyClass {
public:
    int* data;

    MyClass(int val) {
        data = new int(val);
    }

    // No copy constructor
    void show() {
        cout << *data << endl;
    }
};

int main() {
    MyClass obj1(10);
    MyClass obj2 = obj1;  // ❌ default shallow copy

    *obj2.data = 20;

    obj1.show();  // Output: 20 ❌ (should be 10)
}



class MyClass {
public:
    int* data;

    MyClass(int val) {
        data = new int(val);
    }

    // ✅ Deep Copy Constructor
    MyClass(const MyClass& other) {
        data = new int(*other.data);
    }

    void show() {
        cout << *data << endl;
    }
};

int main() {
    MyClass obj1(10);
    MyClass obj2 = obj1;

    *obj2.data = 20;

    obj1.show();  // Output: 10 ✅
    obj2.show();  // Output: 20
}

#include <iostream>

class Counter {
private:
    int value;

public:
    Counter() : value(0) {}

    // ✅ Prefix ++
    Counter operator++() {
        ++value;          // Pehle increment
        return *this;     // Return updated object
    }

    // ✅ Postfix ++ (int dummy parameter)
    Counter operator++(int) {
        Counter temp = *this;  // Save current state
        value++;               // Phir increment
        return temp;           // Return old value
    }

    // ✅ Prefix --
    Counter operator--() {
        --value;
        return *this;
    }

    // ✅ Postfix --
    Counter operator--(int) {
        Counter temp = *this;
        value--;
        return temp;
    }

    void show() const {
        cout << "Value = " << value << endl;
    }
};


Jab aap ++obj likhte hain, to aap pehle object ka value barhate ho, fir uska result use karte ho (prefix).
Aur jab obj++ likhte ho, to pehle purana value use hota hai, aur baad mein increment hota hai (postfix).
Postfix ko differentiate karne ke liye aap int dummy parameter dete ho.

 Recursion kya hoti hai?
Recursion ek technique hai jisme function apne aap ko hi call karta hai, jab tak koi base condition milti hai.

📌 Simple Words:
Function khud ko bar bar call karta hai, har baar ek step chhota ho jata hai, jab tak rukne ka signal mil jaye.

🔸 Real Life Example:
Mirror ke saamne mirror rakh do — reflections infinite nazar aati hain.
Same goes for recursive functions — khud ko call karti hai.

🔶 Basic Example:
✅ C++ mein factorial (5!) ka example:

int factorial(int n) {
    if (n == 0 || n == 1)       // 🔸 Base case
        return 1;
    else
        return n * factorial(n - 1);   // 🔁 Recursive call
}
factorial(5) ka flow:

5 * factorial(4)
  → 4 * factorial(3)
    → 3 * factorial(2)
      → 2 * factorial(1)
        → 1 → Base case → returns 1
🔷 Types of Recursion
1️⃣ Direct Recursion
Jab ek function khud ko hi call kare directly.

✅ Example:

void fun() {
    cout << "Hello" << endl;
    fun();  // 🔁 Direct call to itself
}
2️⃣ Indirect Recursion
Jab ek function doosray function ko call kare, aur wo function pehle wale ko wapas call kare — chain ban jaye.

✅ Example:

void A();  // forward declaration

void B() {
    cout << "Inside B" << endl;
    A();  // 🔁 B calls A
}

void A() {
    cout << "Inside A" << endl;
    B();  // 🔁 A calls B
}
Yahan A → B → A → B … ek loop ban jaata hai = Indirect recursion

🧠 Base Case (Bohat Important)
Har recursive function ke paas base condition (rukne ka signal) hona zaroori hai.
Warna program infinite loop mein chala jaayega ya stack overflow error dega.

📌 Step 2: Return (Bottom to Top)
Return Step	Result Calculation
factorial(1) returns 1	base case hit
factorial(2) returns 2 * 1 = 2	
factorial(3) returns 3 * 2 = 6	
factorial(4) returns 4 * 6 = 24	
factorial(5) returns 5 * 24 = 120
